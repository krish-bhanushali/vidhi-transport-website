Helpful answers

Pickup request questions

Does submitting a pickup request confirm a vehicle?

No. The prepared request must be sent to Vidhi Transport, and the team must review the cargo, route, schedule and vehicle availability before confirming the pickup.

Which cargo details should I include?

Include the exact material, package type and count, total weight, dimensions, stackability, loading method and any classification, document or handling requirement.

Can I request PTL and FTL assessment together?

Yes. Select ‘Please recommend’ and provide complete shipment information so the team can assess the practical movement options.
